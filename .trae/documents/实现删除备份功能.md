# 实现删除备份功能

## 1. 增加唯一ID标识

### 1.1 更新类型定义
在 `src/types/index.ts` 中为 `NvramBackup` 接口添加 `id` 字段，使用整数类型：
```typescript
export interface NvramBackup {
  id: number; // 新增唯一标识，使用整数类型
  nvramName: string;
  psVersion: PsVersion;
  jchipVersion: JChipVersion;
  backupTime: string;
  fileList: string[];
  totalSize: string;
}
```

### 1.2 更新后端结构体
在后端代码中找到 `NvramBackup` 结构体定义，添加 `id` 字段，使用 `u32` 或 `i32` 类型

### 1.3 修改备份生成逻辑
在 `src-tauri/src/modules/backup.rs` 的 `generate_backups` 函数中，为每个生成的备份添加唯一整数id

## 2. 修改还原备份逻辑

### 2.1 更新后端还原命令
修改 `src-tauri/src/modules/commands.rs` 中的 `restore_backup` 命令，使其使用 `id` 作为唯一标识参数

### 2.2 更新前端还原逻辑
修改 `src/components/BackupList.vue` 中的 `handleRestore` 函数，使用选中备份的 `id` 调用后端命令

## 3. 实现删除备份功能

### 3.1 添加删除备份命令
在 `src-tauri/src/modules/commands.rs` 中添加 `delete_backup` 命令：
- 接收 `id` 作为唯一标识参数
- 实现删除备份的逻辑
- 发送状态更新事件

### 3.2 注册删除备份命令
在 `src-tauri/src/lib.rs` 中注册新的 `delete_backup` 命令

### 3.3 添加删除按钮
在 `src/components/BackupList.vue` 的备份详情区域，在"还原此备份"按钮右侧添加"删除此备份"按钮

### 3.4 添加确认对话框
使用浏览器的 `confirm()` 函数，在用户点击删除按钮时显示确认信息

### 3.5 实现删除逻辑
- 在 `BackupList.vue` 中添加 `handleDelete` 函数
- 调用后端的 `delete_backup` 命令，传递选中备份的 `id`
- 删除成功后重新获取备份列表

9. 测试功能完整性

## 5. 技术细节

### 5.1 唯一ID生成
- 后端使用递增整数生成唯一id
- 确保每个备份都有唯一的id

### 5.2 命令参数
- `restore_backup` 命令只需要 `id` 参数，简化调用
- `delete_backup` 命令只需要 `id` 参数

### 5.3 前端调用
- 使用 `invoke` 调用后端命令，传递备份的 `id`
- 调用成功后重新获取备份列表，确保界面数据最新

### 5.4 样式调整
- 确保删除按钮与还原按钮样式协调
- 调整按钮容器布局以容纳两个按钮

这样实现后，每个备份都有唯一整数id，还原和删除操作都通过id进行，提高了操作的准确性和效率。
