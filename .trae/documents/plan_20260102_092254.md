3.3 **文件监听事件中的状态更新**
   ```rust

   // 文件监听事件处理
   std::thread::spawn(move || {
       for res in rx {
           match res {
               Ok(event) => {
                   println!("NVRAM目录发生变化: {:?}", event);
                   
                   // 发送状态更新
                   send_status_update(&app_handle, "info", "NVRAM目录发生变化");
                   
                   // 获取更新后的NVRAM信息
                   let updated_info = get_current_nvram_info(&watch_path);

               }
               Err(e) => {
                   // 发送错误状态
                   send_status_update(&app_handle, "error",

               }
           }
       }
   });
   ```

3.4 **前端事件监听**
   ```typescript
   // 状态信息类型
   interface StatusUpdate {
       level: StatusLevel;
       message: string;
   }
   
   // 状态信息响应式变量
   const statusInfo = ref<StatusUpdate>({
       level: 'info',
       message: '就绪'
   });
   
   // 监听状态更新事件
   onMounted(async () => {
       await listen<StatusUpdate>("status_updated", (event) => {
           statusInfo.value = event.payload;
       });
   });
   ```

3. 状态栏显示最新的状态信息，根据类型显示不同颜色

## 技术亮点

1. **事件驱动设计**：使用Tauri的事件系统实现后端到前端的实时状态更新
2. **解耦设计**：状态信息不再与AppConfig耦合，提高了代码的可维护性
3. **多上下文支持**：在不同上下文中（命令、事件、回调）都能发送状态更新
4. **类型安全**：使用TypeScript确保类型安全
5. **响应式UI**：状态信息更新后，UI自动更新
6. **实时反馈**：用户可以看到操作的实时状态，提升用户体验

通过这些修改，应用程序将实现更灵活、更实时的状态信息更新机制，提升用户体验。
